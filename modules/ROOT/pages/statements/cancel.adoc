= `CANCEL` 语句

SurrealDB中的每个语句都在其自己的事务中运行。如果需要一起做出一系列更改，那么可以将一组语句作为一个单独的事务一起运行，要么整体成功，要么失败而不会留下任何数据修改。虽然如果事务中的任何语句遇到错误，事务将失败，但也可以手动使用 `CANCEL` 语句来取消事务。

== 语句语法

.SurrealQL语法
[source,sql]
----
CANCEL [ TRANSACTION ];
----

== 示例用法

以下查询显示了这个语句的示例用法。

[source,sql]
----
BEGIN TRANSACTION;

-- Setup accounts
CREATE account:one SET balance = 135605.16;
CREATE account:two SET balance = 91031.31;

-- Move money
UPDATE account:one SET balance += 300.00;
UPDATE account:two SET balance -= 300.00;

-- Rollback all changes
CANCEL TRANSACTION;
----

`CANCEL` 不是用来根据条件自动取消事务的，比如在 xref:statements/ifelse.adoc[IF..ELSE] 块中。相反，使用的是 xref:statements/throw.adoc[THROW] 语句。THROW可以跟随任何值，通常是包含错误背景的字符串。

[source,sql]
----
BEGIN TRANSACTION;

-- Setup accounts
CREATE account:one SET balance = 135605.16;
CREATE account:two SET balance = 200.31;

-- Move money
UPDATE account:one SET balance += 300.00;
UPDATE account:two SET balance -= 300.00;

IF account:two.balance < 0 {
    THROW "Not enough funds";
};

COMMIT TRANSACTION;
----
