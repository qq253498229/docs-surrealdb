= `COMMIT` 语句

SurrealDB中的每个语句默认在自己的事务中运行。如果需要一起做出一系列更改，那么可以将一组语句作为一个单独的事务一起运行，要么整体成功，要么失败而不会留下任何数据修改。在这样一个事务的末尾使用 `COMMIT` 语句，使数据修改成为数据库的一个永久部分。

== 语句语法

.SurrealQL语法
[source,sql]
----
COMMIT [ TRANSACTION ];
----

== 示例用法

以下查询显示了这个语句的示例用法。

[source,sql]
----
BEGIN TRANSACTION;

-- Setup accounts
CREATE account:one SET balance = 135605.16;
CREATE account:two SET balance = 91031.31;

-- Move money
UPDATE account:one SET balance += 300.00;
UPDATE account:two SET balance -= 300.00;

-- Finalise all changes
COMMIT TRANSACTION;
----

如果需要在不提交更改的情况下取消事务，可以在任何时候使用以下两个选项：

* xref:statements/cancel.adoc[CANCEL] 手动取消事务，
* xref:statements/throw.adoc[THROW] 取消事务并可选地附带错误消息。THROW是唯一一种可以根据条件取消事务的方式，比如在 xref:statements/ifelse.adoc[IF..ELSE] 块中。
